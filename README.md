
# Sales Performance Dashboard using Power BI

## Project Overview
This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI. It helps visualize sales data and understand business performance through data analysis and visualization.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Project Objectives
- Analyze sales performance.
- Present business data through interactive visualizations.
- Identify sales trends and patterns.
- Support data-driven business decisions.
